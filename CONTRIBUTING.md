# Contributing

Keep CryptoMem a small, offline Volatility plugin. Detection, validation, and
interpretation are separate: a valid address does not establish ownership,
control, balance, transaction activity, or even the presence of wallet software.

Use Python 3.12+, install `requirements.txt`, and run:

```sh
python -m unittest discover -s tests -v
```

Tests use published public examples and generated byte buffers. Never commit
memory images, private keys, seed phrases, case outputs, or local configuration.
Add positive, negative, malformed, encoding, and chunk-boundary fixtures when
changing a detector. Record actual real-image checks separately; mocked process
objects and synthetic buffers do not establish Windows-build compatibility.

Preserve upstream notices for reused material. No network requests, recovered
code execution, full-process dumps, or arbitrary host file writes in analysis.
Output files must use Volatility's file handler. Keep missing pages and exhausted
limits explicit; do not weaken completeness checks for a passing result.
